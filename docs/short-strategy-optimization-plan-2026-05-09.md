# 短线策略优化方案

> 版本：v1.0 | 日期：2026-05-09 | 状态：方案阶段（未实施）
>
> 触发背景：ExhaustionFilter 从"透支检测"重构为"动量质量检测"后，系统性地审视短线策略的完整逻辑链路和剩余盲区。

## 一、当前架构回顾

### 1.1 六维度全景

```
ingest → 6 个 filter 各自打分 (0-100) → combine 固定分母融合 → 硬规则淘汰 → TOP N
```

| 维度 | 权重 | 回看周期 | 核心问题 | 信号类型 |
|------|------|---------|---------|---------|
| `limit` | 0.25 | 1-2 天 | 昨天涨停 → 今天断板反包？ | 正向催化 |
| `moneyflow` | 0.25 | 1-3 天 | 主力今天在买吗？ | 正向催化 |
| `lhb` | 0.20 | 1 天 | 今天上榜了吗？席位如何？ | 正向催化 |
| `sector` | 0.10 | 1-3 天 | 板块今天涨了吗？ | 正向环境 |
| `theme` | 0.10 | 1-2 天 | 概念今天热吗？ | 正向环境 |
| `exhaustion` | 0.10 | 5-11 天 | **动量还健康吗？** | 动量质量 |

### 1.2 ExhaustionFilter 当前状态（v2.6 重构后）

活跃的 3 个信号：

| 信号 | max_penalty | 数据维度 | 检测什么 |
|------|------------|---------|---------|
| 量价背离 | 20 | 日间量价 | 缩量上涨（涨的质量变差）/ 放量滞涨（高位换手） |
| 连涨天数 | 10 | 日间方向 | 散户追涨程度（阳线连续天数） |
| 动量衰减 | 10 | 日间涨幅分布 | 加速度在减速（涨幅集中在前半段） |

已禁用的 2 个信号（max=0）：

| 信号 | 原因 |
|------|------|
| 5 日累计涨幅 | 短线追势策略中，强势股天然涨幅高，惩罚涨幅 = 惩罚最强候选 |
| MA5 偏离度 | 同上，强势股天然偏离均线；且与 5 日涨幅高度共线 |

极端透支由 hard_reject 层处理：
- `max_5d_return_pct: 25`（5 日涨幅 > 25% → 直接淘汰）
- `max_consecutive_up_with_5d_return: ret_5d > 20% + 连涨 ≥ 5 天 → 直接淘汰`

## 二、信号盲区分析

当前 3 个活跃信号都基于**日间聚合数据**（OHLC 的日线收盘形态），唯一的日内数据（open / high / low）没有被利用。

### 2.1 盲区 1：冲高回落（日内出货）

**场景**：
- 股票盘中拉到 +8%，收盘只剩 +2%，全天放量
- 日线看起来：收阳 +2%，量正常偏大
- 放量滞涨不触发（pct_chg=+2% ≥ 2% 门槛，看具体数值）
- 缩量上涨不触发（量没缩）
- 动量衰减不触发（涨幅可能集中在最近 2 天）
- → **exhaustion 分数接近 100**，但日内实际上已经发生了明显的出货

**为什么重要（1-3 天持仓）**：
- 上影线（尤其是长上影 + 放量）是经典的高位卖压信号
- 次日低开概率显著升高
- 短线持仓 1-3 天，次日低开 2% 就吃掉大部分预期收益

**现有信号为什么抓不住**：

| 场景 | 5 日涨幅 | MA5 偏离 | 量价背离 | 连涨 | 动量衰减 | 现有覆盖 |
|------|---------|---------|---------|------|---------|---------|
| 盘中 +8% → 收 +4.5%，放量 | 20% | 触发(已禁用) | ❌ pct_chg 不触发 | 可能触发 | 可能不触发 | **漏判** |
| 盘中 +6% → 收 -1%，放量 | 15% | 触发(已禁用) | 放量滞涨可能触发(pct_chg=-1%<2%) | 不触发 | 不触发 | 部分覆盖 |
| 盘中 +9% → 收 +1.8%，量正常 | 18% | 触发(已禁用) | ❌ 都不触发 | 可能触发 | 可能不触发 | **漏判** |

关键盲区是第一种：**冲高回落但收盘仍为正且涨幅不小**的场景。

### 2.2 盲区 2：低开高走的"假强势"

**场景**：
- 股票低开 -3%，盘中拉回收 +1%，看起来收阳（close > open）
- 连涨天数计数会增加（收阳线）
- 但相对昨收跌了 2%（pct_chg = -2%）
- 这种"假阳线"被连涨天数当作强势信号，实际上相对昨收在走弱

**当前处理**：
- `_count_consecutive_up` 用 `close > open` 判定，会把它计为"涨日"
- blink 相对昨收的走势完全没被考虑

**影响评估**：较小。因为：
- 低开高走的假阳线在 A 股本身不常见（多数情况低开低走或高开高走）
- 即使误计为连涨，连涨惩罚上限只有 10 分，权重 0.10，最终影响 < 1 分
- 如果连涨天数本身就在 3 天以下，根本不触发惩罚

**结论**：暂不处理。

### 2.3 盲区 3：连续缩量上涨（渐进衰减）

**场景**：
- 近 4 日量能：2000 → 1800 → 1500 → 1200（逐日递减）
- 近 4 日价格：100 → 103 → 106 → 110（逐日递增）
- 单日缩量上涨检查：今日量 1200 > 5 日均量 × 0.6 = 1620 × 0.6 = 972 → 不触发
- 但连续 4 日缩量上涨，动量衰竭趋势明显

**为什么暂不处理**：
- 需要 4-5 日的成交量趋势判断，逻辑复杂度显著增加
- 与现有单日缩量上涨信号高度共线（连续缩量的最后一天往往是单日缩量最严重的一天）
- 算力成本增加（均量趋势、量价趋势两条线交叉验证）

**结论**：放到后续迭代。

### 2.4 信号盲区优先级汇总

| 优先级 | 盲区 | 新增信号 | 数据需求 | 复杂度 |
|--------|------|---------|---------|--------|
| **P0** | 冲高回落 | 上影线/振幅比 | high, open, close（已有） | 低 |
| P1 | 连续缩量上涨 | 量能趋势 | 4-5 日成交量（已有） | 中 |
| P2 | 假阳线 | close vs pre_close | close, open（已有） | 低（但影响极小） |

**本次方案聚焦 P0**：冲高回落检测。

## 三、冲高回落信号设计

### 3.1 信号定义

```
上影线长度 = high - max(open, close)
实体长度   = abs(close - open)
总振幅     = high - low

上影线占比 = 上影线长度 / 总振幅
```

经典技术分析中，"射击之星"（shooting star）的判定标准：
- 上影线占比 > 60%（即上影线占当日振幅的 60% 以上）
- 实体较小，位于全日波动区间的下半部

对于量化场景，我们使用三个核心指标：

**指标 A：上影线占比**

```
upper_shadow_ratio = (high - max(open, close)) / (high - low)
```

**指标 B：收盘位置**

```
close_position = (close - low) / (high - low)
```

`close_position` 接近 0 表示收在全日最低点附近（最弱），接近 1 表示收在全日最高点附近（最强），0.5 表示收在中间。

**指标 C：盘中冲高幅度**

```
high_return_from_pre_close = (high - pre_close) / pre_close * 100
```

`pre_close` 指上一交易日收盘价。这个指标直接回答"今天是否真的往上冲过"，
用于过滤窄幅震荡中因 `high - low` 分母过小导致的上影线占比虚高。

### 3.2 触发条件

冲高回落需要**同时**满足四个条件，缺一不可：

| 条件 | 阈值 | 含义 |
|------|------|------|
| 上影线占比 > 60% | `upper_shadow_ratio > 0.6` | K 线形态上存在明显长上影 |
| 收盘位置 < 50% | `close_position < 0.5` | 收盘在全日振幅的下半区（确认回落，而非高位盘整） |
| 近 3 日涨幅 > 5% | `ret_3d > 5%` | 有足够的涨幅空间才谈得上"冲高"（横盘股的上影线是噪音） |
| high 相对昨收涨幅 >= 3% | `high_return_from_pre_close >= 3.0` | 当天最高价必须真的向上冲过，过滤窄幅震荡假上影 |

**为什么需要四个条件同时满足**：

- 条件 1 单独用：大盘回落拖累的股票也会被惩罚，但它是无辜的
- 条件 2 单独用：低开低走的股票 close_position 也低，但那是单边下跌不是冲高回落
- 条件 3 单独用：跟 5 日涨幅惩罚一样的问题
- 条件 4 单独用：只说明盘中曾涨，不说明收盘被砸，也不说明近期有获利盘
- 四者同时满足 → 高置信度：股票在近期上涨后，今天盘中明显冲高，但收盘被砸回低位

`high_return_from_pre_close` 比 `intraday_amplitude_pct` 更适合作为第 4 个条件：
振幅只衡量全天波动，不能直接说明"向上冲"；high 相对昨收涨幅直接衡量当天盘中最高浮盈。
例如近 3 日涨幅 8%，今天 `high=10.03, low=10.00, close=10.01`，
上影线占比可能达到 0.67，但 high 相对昨收涨幅不足 3%，不应判为冲高回落。

### 3.3 惩罚公式

```python
if not (
    upper_shadow_ratio > threshold_upper_shadow_ratio
    and close_position < threshold_close_position
    and ret_3d > threshold_upper_shadow_3d_return
    and high_return_from_pre_close >= threshold_high_return_from_pre_close
):
    return 0

# 基础惩罚 = 上影线占比 × max_penalty（线性）
# 收盘位置越差，惩罚越重

severity = upper_shadow_ratio  # 0.6 ~ 1.0
# close_position 取值范围 0.0 ~ 1.0，但触发要求 < 0.5，实际生效域 0.0 ~ 0.5
# → close_penalty_factor 在触发域内为 1.0 ~ 1.25
close_penalty_factor = 1.0 + (0.5 - close_position) * 0.5

penalty = severity * max_penalty * close_penalty_factor
penalty = clamp(penalty, 0, max_penalty)
```

其中：
- `upper_shadow_ratio = 0.6` 时 severity 最低，= 1.0 时 severity 最高
- `close_position = 0.5`（收在中间，不触发）→ factor = 1.0
- `close_position = 0.0`（收在全日最低）→ factor = 1.25，加重 25%
- `close_position = 0.25`（收在下 1/4）→ factor = 1.125

### 3.4 极端场景验证

| 场景 | pre_close | open | high | low | close | 上影线占比 | 收盘位置 | 3d 涨幅 | high 相对昨收 | 触发？ | 惩罚（max=15） |
|------|-----------|------|------|-----|-------|-----------|---------|---------|--------------|--------|---------------|
| 典型冲高回落 | 10.0 | 10.0 | 10.8 | 10.0 | 10.15 | (10.8-10.15)/(10.8-10)=0.81 | (10.15-10)/(10.8-10)=0.19 | 8% | 8% | ✅ | 0.81×15×1.15≈14.0 |
| 冲高后高位整理 | 10.0 | 10.0 | 10.8 | 10.0 | 10.5 | (10.8-10.5)/0.8=0.375 | 0.625 | 8% | 8% | ❌ 上影线不够 | 0 |
| 大盘普跌拖累 | 10.5 | 10.5 | 10.55 | 10.0 | 10.05 | (10.55-10.5)/0.55=0.09 | 0.09 | 8% | 0.5% | ❌ 上影线不够 / 没冲高 | 0 |
| 低开高走收阳 | 10.0 | 9.5 | 10.2 | 9.5 | 10.1 | (10.2-10.1)/0.7=0.14 | 0.86 | 8% | 2% | ❌ 不是回落 / 冲高不足 | 0 |
| 光头光脚大阳 | 10.0 | 10.0 | 10.8 | 10.0 | 10.8 | (10.8-10.8)/0.8=0 | 1.0 | 8% | 8% | ❌ | 0 |
| 横盘上影线 | 10.0 | 10.0 | 10.3 | 9.9 | 10.0 | 0.75 | 0.25 | 2% | 3% | ❌ 涨幅不够 | 0 |
| 窄幅假上影 | 10.0 | 10.0 | 10.03 | 10.0 | 10.01 | 0.67 | 0.33 | 8% | 0.3% | ❌ 当天冲高不足 | 0 |

横盘上影线不触发，因为近 3 日涨幅不足 5%——这是关键的门槛机制，避免对震荡市中的随机上影线过敏。
窄幅假上影线不触发，因为 high 相对昨收涨幅不足 3%，避免 `high - low` 过小导致比例误判。

### 3.5 惩罚上限

建议 `penalty_upper_shadow_max: 15`，与连涨天数（10）、动量衰减（10）同级。

理由：
- 上影线可能是"大盘午后跳水拖累"而非"个股出货"，信号不如量价背离确定
- 15 分上限 × 0.10 权重 = 对 final_score 最大影响 1.5 分，提供区分度但不主导
- 极端情况下（5 日涨幅 > 25%）已被 hard_reject 兜底

### 3.6 配置项

```yaml
exhaustion_filter:
  # 冲高回落（v2.7 新增）
  penalty_upper_shadow_max: 15        # 冲高回落惩罚上限
  threshold_upper_shadow_ratio: 0.6   # 上影线/振幅 > 此值
  threshold_close_position: 0.5       # 收盘位置 < 此值（下半区）
  threshold_upper_shadow_3d_return: 5.0  # 近 3 日涨幅 > 此值才检查
  threshold_high_return_from_pre_close: 3.0  # high 相对昨收涨幅 >= 此值才检查
```

全部可热调。设 `penalty_upper_shadow_max: 0` 关闭此信号。

## 四、ExhaustionFilter 完整信号体系（优化后）

### 4.1 信号全景

```
score = 100 - Σ(active penalties)

6 个信号（4 个活跃 + 2 个禁用）：
  [活跃] 1. 冲高回落     max=15  日内形态   ← v2.7 新增
  [活跃] 2. 量价背离     max=20  日间量价
  [活跃] 3. 连涨天数     max=10  日间方向
  [活跃] 4. 动量衰减     max=10  日间涨幅分布
  [禁用] 5. 5 日涨幅     max=0   ← 已禁用
  [禁用] 6. MA5 偏离     max=0   ← 已禁用
```

### 4.2 信号维度的完整覆盖

| 数据层级 | 信号 | 检测什么 |
|---------|------|---------|
| **日内形态** | 冲高回落 | 盘中冲高后被打回 → 高位卖压出现 |
| **日间量价关系** | 量价背离 | 缩量上涨（涨不动了）/ 放量滞涨（高位换手） |
| **日间方向** | 连涨天数 | 连续阳线 → 散户追涨程度 |
| **日间涨幅分布** | 动量衰减 | 涨幅集中在前半段 → 加速度在减速 |

四个信号各自覆盖不同的数据维度，无强共线性。

注意：冲高回落当天如果同时放量，可能和放量滞涨叠加惩罚（15+16=31 分）。但两者触发条件不重叠——冲高回落不要求放量，放量滞涨不要求上影线——属于合理交叉而非冗余。受同一事实（"今日价格行为弱"）驱动的叠加是有限的，不会导致重复惩罚同一信号。

### 4.3 max Σpenalties 分析

| 信号 | max_penalty |
|------|------------|
| 冲高回落 | 15 |
| 量价背离 | 20 |
| 连涨天数 | 10 |
| 动量衰减 | 10 |
| **合计** | **55** |

max Σpenalties = 55，在最极端的"四信号全触发"场景下，score = clamp(100-55, 0, 100) = 45。不会归零。

对 final_score 的最大影响：45 × 0.10 = 4.5 分（vs 动量健康的 100 × 0.10 = 10 分，差距 5.5 分）。在 0-100 的 final_score 区间中，5.5 分的差距足以改变排序，但不会主导。

### 5.1 当前硬规则（共 8 条）

两个透支硬规则的阈值（25%、20%+5 天）与 ExhaustionFilter 当前禁用的 5 日涨幅信号口径一致，但 hard_reject 是二值淘汰（过了门槛直接杀），exhaustion 是梯度惩罚（越高扣越多）。二者互补，当前设计合理。

唯一的问题是 `negative_announcement_keywords` 因 anns_raw 表为空而静默失效，但这属于数据接入问题，不在本次方案范围。

## 六、系统级建议

以下建议超出 ExhaustionFilter 的范围，但属于短线策略整体优化值得考虑的：

### 6.1 权重分配的再平衡

当前权重：

```
limit: 0.25 | moneyflow: 0.25 | lhb: 0.20 | sector: 0.10 | theme: 0.10 | exhaustion: 0.10
```

**问题**：exhaustion 作为唯一的"质量检查"维度，权重只有 0.10。而正向维度合计 0.90。这意味着 4 个正向信号满格但动量质量极差的股票，仍然能拿到 90% 的分数。

**但当前设计已经够用**，原因：
- exhaustion 是修饰维度（fine-tune 排序），不是决策维度
- 极端透支已被 hard_reject 直接淘汰，exhaustion 只做梯度区分
- 如果把 exhaustion 提到 0.15 或 0.20，阈值回测还没有做，可能过度惩罚自然回调的强势股

**建议**：待 Phase 2.5 回测校准后，根据 exhaustion 信号的 IC 和胜率贡献决定是否调整权重。

### 6.2 limit 维度的覆盖缺口

limit 维度只覆盖了"昨天涨停今天断板反包"的股票。一只股票从来没涨停过，但连续小阳线推升 8 天，limit 维度给 0 分。这在当前体系下不是问题（moneyflow / sector / theme / lhb 仍可正分），但如果要找"温和推升型"的短线标的，这个缺口值得关注。

**可能的方案**（不在本次范围）：在 limit 维度新增"非涨停强势"子项——近 N 日涨幅超板块但无涨停的股票给少量加分。

### 6.3 数据新鲜度

ExhaustionFilter 拉取最近 11 个交易日的 K 线。对于 T+1 制度的 A 股，11 个交易日约等于 2 周。这个窗口足够计算所有 5/3/2 日指标。但如果后续要加更长的窗口（如 20 日均量对比），需要把 `trade_dates = 11` 调大。

### 7.3 detail 记录与日志修正

`score_all` 中需新增冲高回落的 detail 字段，供报告和 AI 使用：

```python
# 冲高回落（信号 1）
penalty_shadow = _penalty_upper_shadow(klines, today, cfg)
if penalty_shadow > 0:
    score -= penalty_shadow
    detail["penalty_upper_shadow"] = round(penalty_shadow, 1)
    detail["upper_shadow_ratio"] = round(upper_shadow_ratio, 2)
    detail["close_position"] = round(close_position, 2)
    detail["high_return_from_pre_close"] = round(high_return_from_pre_close, 2)
# 振幅记录供监控（字段有效时即使未触发也记录，便于 Phase 3 分析误触发率）
if high is not None and low is not None and close > 0:
    detail["intraday_amplitude_pct"] = round((high - low) / close * 100, 2)
```

注意：
- `upper_shadow_ratio` 和 `close_position` 在惩罚触发时记录，与其它 penalty 行为一致
- `high_return_from_pre_close` 在惩罚触发时记录，用于说明当天确实冲高
- `intraday_amplitude_pct` 在字段有效时始终记录（成本为零），供 Phase 3 监控低振幅股是否误触发率高；如后续需加 `min_amplitude` 门槛可直接在 yaml 配置
- `_penalty_upper_shadow` 纯函数内部需独立做 `len(klines) >= 4` 和 `high - low <= 0` 防御，不自依赖调用方前置条件
- `_penalty_upper_shadow` 维持现有 `_penalty_*` 纯函数风格，只返回 `float`；`score_all` 调用方自行计算并记录展示 metrics，保持与 `ret_5d_pct` / `ma5_deviation_pct` 的现有模式一致
- 计算 `intraday_amplitude_pct` / `upper_shadow_ratio` / `close_position` / `high_return_from_pre_close` 前，需确保 `open/high/low/close/pre_close` 都有效且分母大于 0

同时修正 `score_all` 末尾 logger 消息中的过时措辞（"严重透支" → "动量质量差"）。

## 八、风险与注意事项

1. **大盘跳水相关性**：下午 2:30 大盘跳水会制造大量"冲高回落"K 线，这些股票不是个股问题而是系统性风险。当前设计用 `close_position < 0.5` 部分缓解（大盘跳水时多数股票都收在低位，但相对强度依然可比），但不能完全消除。**缓解措施**：可用全市场涨跌家数或指数日内走势做信号衰减（但需要指数日内数据，属 Phase 3 范围）。

2. **一字板误判**：一字板（open=high=low=close）振幅为 0，上影线占比计算会除零。纯函数需要用 `if high - low <= 0: return 0` 防御。

3. **涨停股的冲高回落**：涨停股被 `exclude_today_limit_up` 硬淘汰，不会进入候选池。但 exhaustion 仍会给它出分（全市场出分），冲高回落对涨停股没有意义（炸板才是问题，而这已被 LimitFilter 的 `open_times_penalty` 覆盖）。**不需要特殊处理**，全市场出分没有害处。
